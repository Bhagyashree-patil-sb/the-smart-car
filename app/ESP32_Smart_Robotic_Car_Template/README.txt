ESP32 Smart Robotic Car - MIT App Inventor Template

This is a project template package containing:
- Screen layout specification
- Blocks logic specification
- Component list
- ESP32 command mapping

Use these files to build the project in MIT App Inventor.

Commands:
M = Manual
A = Auto
1 = Home
2 = School
3 = Office
4 = Hospital
F = Forward
B = Backward
L = Left
R = Right
S = Stop
0-9 = Speed
